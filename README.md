# 投資研究ソフト

自分専用の投資練習ソフト。**仮想の売買を、実際の株価の値動きで**行い、
自分の予測を記録して後で答え合わせできる。日本株・米国株に対応。

→ 全体の設計は [設計書.md](設計書.md) を参照。

## 起動のしかた

1. 初回だけ、必要なライブラリを入れる（済んでいれば不要）:

```bash
pip install -r requirements.txt
```

2. 起動する（どちらでもOK）:

- `run.bat` をダブルクリック
- または端末で:

```bash
python run.py
```

3. ブラウザで **http://127.0.0.1:8000** を開く。
4. 右上の **更新** を押すと、実データ（株価・指数）を取得する。
   - 常時通信はしない。**更新ボタンを押したときだけ**取りに行く。
   - 止めるときは端末で `Ctrl+C`。

## 3つの画面

| 画面 | できること |
| --- | --- |
| **マーケット** | 指数タイル・ウォッチリスト（初期約400銘柄：日経225＋S&P主要）・騰落率ランキング・自動更新。銘柄は複数まとめて入力でき、テーマ別プリセットでも一括追加できる |
| **ランキング** | 値上がり/値下がり/出来高急増/AIサイン/AIモデルのランキング、セクター別、スクリーナー |
| **仮想投資** | 日本株口座(¥10万)/米国株口座($700)で売買、損益・取引履歴（勉強代として使い切れる小さめの額） |
| **AI分析・予測** | テクニカル指標とサイン、機械学習モデル、予測の記録と**的中率(答え合わせ)** |
| **設定** | 使い方の目的（短期スイング/長期じっくり）、手数料率、練習のリセット（表示・自動更新はブラウザに自動記憶） |

- 銘柄の行やタイルをクリックすると、**チャート・指標・関連ニュース・売買・予測**の詳細が開く。
- ウォッチリストは**検索・市場フィルタ（日本/米国）・列で並べ替え・×で削除**ができる。
- 仮想投資タブに**資産推移グラフ**、注文の**概算金額**、保有の**「全部売る」**、取引履歴の**手数料**表示。予測は×で削除できる。
- 仮想投資タブの保有行は**クリック（または「📈 チャート」）でチャート・指標・売買・予測**を開ける。
- 銘柄チャートは**期間を切替**できる（1日/5日/1ヶ月/3ヶ月/6ヶ月/1年/5年/全期間）。短期（1日・5日）は**分足で時刻つき**。
- 銘柄チャートは**ホイールで拡大・縮小**（月日が細かく／広くなる）、**ドラッグで左右に移動**して表示する期間の位置をずらせる。**「表示をリセット」**で元に戻る（chartjs-plugin-zoom）。
- チャートは**カーソルを合わせると日付（短期は時刻）と値をツールチップ表示**し、縦のガイド線も出る。
- **取引履歴の行をクリック**すると、その銘柄のチャートに**約定した地点（買い=緑・売り=赤）**を印として表示する。
- 銘柄チャートに**ニュースが入った日を△印**（ポジ=緑/ネガ=赤/中立=灰）で表示。ホバーでその日の見出しが読め、「このニュースの後に下がった」が見える。※無料ニュースは直近数日ぶんが中心。
- 直近の値動きの傾きを右へ延ばす**予測の点線**（下げ=赤/上げ=緑、点線）を表示。「この傾きが続いたら」の目安（断定ではない）。
- AI分析・予測タブに**「最近見た銘柄」チップ**。毎回入力しなくても、分析/表示した銘柄をクリックして呼び出せる（この端末のブラウザに記憶）。
- 設定タブの**「使い方（目的）」**で、**短期（スイング）＝チャート既定1ヶ月・予測5営業日** と **長期（じっくり）＝チャート既定1年・予測20営業日** を切替。銘柄チャートの最初に出る期間と予測の既定日数が変わる（期間ボタンでいつでも変更可）。既定は短期。
- 銘柄詳細に**関係性**を表示（すべて実データ由来・推測なし）：**相対強弱**（指数比・同業種平均比で強い/弱い＝相対評価）と、**よく一緒に動く/逆に動く銘柄**（日次リターンの相関。NASDAQ・SOX・VIXなど指数も手掛かりに含む。チップをクリックで連鎖的にたどれる）。
- マーケットタブに**セクター騰落マップ**（業種ごとの平均騰落率を色分け。全体の地合いが一目で分かり、クリックでその業種に絞り込み）。
- 市場指数の上に**当日の地合いサマリー帯**（きょう何が起きているかを一言で）。上昇/下落の数・平均騰落・最も強い/弱い業種・VIX を並べ、株価指数の下げ＋VIX上昇なら「リスク回避寄り」等と**観測**を示す。※予測・助言ではなく、原因（ニュース）の断定もしない。
- 予測の記録は、期限前の**判定待ち**でも**「現時点で基準比±何%」**と残り日数、**予測どおり/逆行中**を表示（答え合わせ前の途中経過が見える）。
- 予測の記録に**想定損益**列。上部の**想定額**（既定10万円・ブラウザ記憶）を「予測どおりに賭けていたら、いま±何円か」で各行に表示（下げ予測は下落で利益＝符号反転。手数料なし）。
- 銘柄詳細チャートの下に**「指数を重ねる」トグル**（丸いボタン型で分かりやすく・説明文つき）。対応する指数（日本株＝日経平均／米国株＝S&P500）を同じ期間・右軸で重ね、**個別株が指数に連動しているか**を目で見られる（数値の連動は「関係性」の相関で確認。指数そのものを開いたときは非表示）。
- 銘柄詳細に**「曜日・季節のクセ（過去の統計）」**。保存済み価格から、**曜日ごとの平均リターン・勝率・日数**と**月別の平均**（ヒート表示）を集計（`/api/seasonality`）。平均プラス/マイナスの曜日も示す。あわせて**暦のアノマリー**（月曜効果・1月効果・Sell in May 等）を“諸説ある教養”として紹介。**サンプルが少ないと偶然のブレが大きい・過去であって未来の保証ではない・助言ではない**ことを明記。
- 銘柄詳細に**「なぜ動いた？（AIの見立て）」**。きょうの騰落を **①市場全体の地合い（対応指数） ②同業種の平均 ③この銘柄固有の動き** に機械的に分解し、「地合いで説明できる／業種要因／固有の弱さ・強さ」を言い分ける。固有の弱さのときだけ**悪材料の候補ニュース**を添える（無関係に見える場合がある旨も明記）。**相関であって因果ではない・鵜呑みにしない**という免責を必ず表示。原因（ニュース）の断定はしない。
- 銘柄詳細の指標に**「25日線からの乖離（行き過ぎ度）」**を表示。平均から±何%離れているかと、RSIの**買われすぎ(≥70)／売られすぎ(≤30)**を添え、大きく離れていれば「平均回帰が起きやすいとされる水準」と**事実として**示す（上がる/下がるの断定はしない）。平均回帰の練習の目安。
- 銘柄詳細の上部に**「これは何？」の説明**。指数・ETF・為替・金利・コモディティ（VIX＝恐怖指数、SOX＝半導体指数、ドル円、米10年金利 等）や主要銘柄をやさしい日本語で説明。個別説明が無い銘柄は**業種のざっくり補足**を表示（`frontend/about.js`）。
- **VIX関連ETF/ETN**（VXX・UVXY・SVXY・VIXY）、**指数ETF**（SPY・QQQ・DIA・IWM・SOXX・SMH）、**コモディティ/債券ETF**（GLD・SLV・USO・TLT）を追加。VIXが動く日に連動して売買・観察できる。
- 右上で**表示テーマ**を**ライト／ダーク／暗め（OLED）**から選べる（この端末のブラウザに記憶）。数字は等幅フォントで揃え、チャートもテーマに追従。
- 銘柄チャートはライブ取得が**レート制限(429)で失敗したとき、保存済みの日足にフォールバック**して表示する（空白や500にならない）。
- マーケットタブに**「値動きが大きい銘柄」**の動的リスト。直近の日次変動率のブレ(vol)が大きい順で、**更新のたびに入れ替わる**（収まれば外れる）。各銘柄を**両方向**（上下に振れる＝平均回帰の練習向き）と**異常**（一方向に飛ぶ・急変＝ニュース等。普通の予測から外して見る）に自動分類し、フィルタで絞れる。
- ウォッチリストは**業種（セクター）で絞り込み**でき、一度に出すのは60件まで（「もっと見る」で追加）。約400銘柄でも見やすい。
- 仮想投資タブ上部に**市場ステータス（日本/米国の 取引中・閉場）**を表示。閉場中は値が動かないのが正常。**「保有の最新値を取得」**で保有銘柄だけ最新値に更新できる。

- 銘柄の行やタイルをクリックすると、**チャート・売買・予測**の詳細が開く。
- 日本株は日本株口座(円)、米国株は米国株口座(ドル)に自動で振り分く。

## 内部メモ（安定性）

- SQLite は **WALモード**で動く（読み取りが書き込みをブロックしないので同時アクセスに強い）。
- 自動更新（最新終値の取り直し）は**並列取得**（最大16並列）。約400銘柄でも数秒で終わる。
- 市場ステータスは各市場の**現地時刻（タイムゾーン）**で判定するので、米国の夏/冬時間のズレが出ない。東証は後場15:30まで対応。
- 売買は **1つの書き込みトランザクション＋UPSERT**で処理し、連続・同時の約定でも「UNIQUE制約」や「database is locked」で失敗しない。ロック時は自動で数回リトライする。

## 注意

- 予測は**断定ではなく参考**。当てる魔法ではなく「自分の読みを記録して振り返る」ための道具。
- 無料データは遅延あり。表示は実データだが、実際の取引判断にそのまま使わない。
- 手数料・スリッページは無しの練習用。現実の売買とは差がある。
